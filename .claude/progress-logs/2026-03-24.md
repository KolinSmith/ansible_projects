## Session 1

**Focus**: Design and implement `install_obsidian` Ansible role; fix broken Obsidian sync chain

### Background

Obsidian sync chain (iPhone → Voyager → GitHub) had been broken since 2026-03-10 because Obsidian was not installed/running on Voyager. The nightly git cron (from `install_obsidian_vault`) was pushing stale files.

### install_obsidian role — MERGED (PR #45)

Implemented a new `install_obsidian` role that runs Obsidian headlessly on Voyager using Xvfb.

**Approach:**
- `xvfb.service` (root): starts Xvfb on virtual display `:99`
- `obsidian.service` (dax): runs `obsidian --no-sandbox --disable-gpu`, depends on xvfb
- `--disable-gpu` is required — GPU subprocess crashes in virtual display environments
- dpkg-query version check for idempotency (bumping `obsidian_version` triggers reinstall)
- `obsidian_version` pinned to `1.12.7` (Obsidian's auto-updater updates asar but not Electron binary)

**First-time login:** Used `ssh -X` X11 forwarding with XQuartz on MacBook to get a GUI session, logged into Obsidian Sync, set vault to `~/wiki/`.

**Fixes during deployment:**
- Added `--disable-gpu` after discovering GPU subprocess crash in Xvfb
- Vault synced to `~/wiki/wiki/` (wrong subfolder) — fixed by editing `~/.config/obsidian/obsidian.json` and restarting
- Stale singleton lock from manual run caused crash loop — cleaned up `~/.config/obsidian/Singleton*` and `/tmp/scoped_dir*`
- Obsidian installer was outdated (1.8.7 vs asar 1.12.7) — installed `obsidian_1.12.7_amd64.deb`, bumped defaults

**Files changed:**
- `roles/install_obsidian/defaults/main.yml` (new)
- `roles/install_obsidian/tasks/main.yml` (new)
- `roles/install_obsidian/handlers/main.yml` (new)
- `roles/install_obsidian/templates/xvfb.service.j2` (new)
- `roles/install_obsidian/templates/obsidian.service.j2` (new)
- `roles/install_obsidian/README.md` (new — full XQuartz login procedure, troubleshooting, upgrade guide)
- `playbooks/dev_server_provision/dev_server_provision.yml` — inserted `install_obsidian` before `install_obsidian_vault`
- `README.md` — added roles table, hosts table, playbook run command
