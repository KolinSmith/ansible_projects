**Issues Fixed**:

1. **Missing entrypoint causing exec failure** (docker_projects)
   - Error: `exec: "daemon": executable file not found in $PATH`
   - Root cause: Image has no ENTRYPOINT, only CMD `[/bin/forgejo-runner]`, so `command: daemon` tried to exec "daemon" directly
   - Fix: Changed to `command: /bin/forgejo-runner daemon`
   - Committed to PR #26: `fix/forgejo-runner-daemon-and-beszel`

2. **Expired registration token**
   - Error: `runner registration token not found` when attempting registration
   - Token in .env (`133afed-5326551-e26a6c-58324328`) was stale/regenerated on Forgejo side
   - User generated new token from Forgejo UI: `NKgrKm6AHqZH6C3lxE5S0t1Wk4OMmS4ieMTdWonJ`
   - Updated .env on server and ran registration successfully
   - Registration created `.runner` file in `docker_runner_data` volume

3. **Docker socket permission denied** (docker_projects)
   - Error: `permission denied while trying to connect to the Docker daemon socket`
   - Analysis:
     - Container ran as `user: "1000:1000"`
     - Host socket: `srw-rw---- root:docker(999)`
     - Container user not in docker group → no socket access
   - Fix: Changed to `user: "1000:999"` (keep UID 1000 for /data volume ownership, GID 999 for docker group)
   - Rationale: `.runner` file owned by 1000:1000 from registration, UID must match for write access
   - Committed to PR #26: `fix/forgejo-runner-daemon-and-beszel`
